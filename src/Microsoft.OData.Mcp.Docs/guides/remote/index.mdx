---
title: "Remote MCP"
description: "Put MCP on the OData API you ship. Customers point their harness at {prefix}/mcp."
---

Remote MCP is what you offer **your customers**. They stay in Claude Desktop, Cursor, Claude Code, or another harness, pointed at your `/mcp` URL, and ask about *their* data on *your* API.

Your OData API does not change. MCP is a sibling at `{yourRoute}/mcp`.

Package: [`Microsoft.OData.Mcp.AspNetCore`](https://www.nuget.org/packages/Microsoft.OData.Mcp.AspNetCore/).
