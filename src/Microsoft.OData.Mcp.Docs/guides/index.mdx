## Remote MCP

A NuGet package on the OData API you already host. Package: `Microsoft.OData.Mcp.AspNetCore`.

<CardGroup cols={2}>
  <Card title="Add Remote MCP to your API" href="/guides/remote/setup">
    `AddODataMcp` and `UseODataMcp`. Customers paste `https://your-host/odata/mcp` into the harness.
  </Card>
  <Card title="Tune Remote MCP" href="/guides/remote/advanced">
    Product sentence, which sets to expose, canned prompts, rate limits.
  </Card>
  <Card title="Long-running actions" href="/guides/remote/tasks">
    `[McpTask]` so the harness waits while shipping, a report, or a browser hop finishes.
  </Card>
  <Card title="Ask the operator to open a URL" href="/guides/remote/elicitations">
    `[McpElicitUrl]` plus a waiter. Tokens stay out of the chat.
  </Card>
  <Card title="Lock Remote MCP like the API" href="/guides/remote/authentication">
    `RequireAuthorization` and protected resource metadata for the harness.
  </Card>
</CardGroup>
