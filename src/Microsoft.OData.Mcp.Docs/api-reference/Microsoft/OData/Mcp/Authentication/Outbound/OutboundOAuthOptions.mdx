## Summary

Operator-supplied and discovered outbound OAuth settings for a single remote OData service — the
options CLI hop 2 (`ODataOutboundAuthHandler`, `OutboundOAuthClient`, and the grant classes)
runs on.

## Remarks

Per `specs/v3/AUTHENTICATION.md` this type is named `OutboundOAuthOptions`, deliberately not
`ClientOAuthOptions` — that SDK type is hop 1's MCP-transport options and must not be reused here.
It carries no certificate properties in v1.

## Examples

```csharp
var options = new OutboundOAuthOptions
{
    ClientId = "my-cli-client",
    Scopes = ["offline_access"],
    Grant = OutboundGrantKind.DeviceCode
};

options = OutboundOAuthOptions.FromEnvironment(options);
options.Validate();
```
