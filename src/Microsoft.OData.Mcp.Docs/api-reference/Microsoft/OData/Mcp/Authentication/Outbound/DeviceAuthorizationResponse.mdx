## Summary

The RFC 8628 section 3.2 device authorization response returned from a device authorization endpoint.

## Remarks

Deserialized exclusively through [OutboundOAuthJsonContext](https://learn.microsoft.com/dotnet/api/microsoft.odata.mcp.authentication.outbound.outboundoauthjsoncontext) (AOT: JSON source-gen; no
reflection). [DeviceAuthorizationResponse.Interval](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/DeviceAuthorizationResponse#interval) is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) when the server omits it; RFC 8628
callers treat an absent interval as five seconds, but this type does not bake that default in so the
distinction between "absent" and "explicitly five" survives for callers that care.

## Examples

```csharp
var response = JsonSerializer.Deserialize(json, OutboundOAuthJsonContext.Default.DeviceAuthorizationResponse);
var pollInterval = response!.Interval ?? 5;
```
