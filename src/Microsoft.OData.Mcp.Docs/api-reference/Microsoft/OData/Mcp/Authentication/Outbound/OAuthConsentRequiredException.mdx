## Summary

Thrown when interactive sign-in is required to complete an outbound OAuth grant and
[OutboundOAuthOptions.ConsentPresenter](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/OutboundOAuthOptions#consentpresenter) is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) — the mid-session path,
where the caller (an MCP tool invocation) must elicit the operator instead of blocking on stderr.

## Remarks

This type lives in `Microsoft.OData.Mcp.Authentication.Outbound`, not Tools, so Authentication never
references Tools. Per `AUTH-12` the wrapped [OAuthConsentRequiredException.Request](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/OAuthConsentRequiredException#request) never carries an access token, a
refresh token, or a `device_code` — only what is needed to complete sign-in out of band. This type
is not marked `[Serializable]`.

## Examples

```csharp
throw new OAuthConsentRequiredException(consentRequest);
```
