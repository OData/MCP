## Summary

Runs the RFC 6749 section 4.4 client credentials grant: a confidential client presents its own
identifier and secret and receives an access token, with no end user and no elicitation anywhere in the
path.

## Remarks

Per `specs/v3/AUTHENTICATION.md` "Grants → Client credentials" the client authentication method is
`client_secret_post` whenever the authorization server advertises it — or advertises nothing at all,
which RFC 6749 leaves open — and `client_secret_basic` otherwise; v1 is secret-only, with no client
certificate. Per `AUTH-12` the secret is never logged: it travels only in the form or the
`Basic` header [TokenEndpointClient](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/TokenEndpointClient) builds, and the Information line here carries only
the redacted token shape.

A client credentials response carries no refresh token — there is no end user session to refresh — so a
caller whose access token has expired re-runs this grant rather than looking for one.

## Examples

```csharp
var response = await grant.AcquireAsync(metadata, "daemon", clientSecret, "read", resource, cancellationToken);
var token = response.ToTokenContainer(
    previousRefreshToken: null,
    clientId: "daemon",
    clientSecret: clientSecret,
    authorizationServer: metadata.Issuer!,
    tokenEndpointAuthMethod: ClientCredentialsGrant.ResolveAuthMethod(metadata));
```

### <Icon icon="function" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> AcquireAsync

Obtains an access token for the client itself.

#### Syntax

```csharp
public System.Threading.Tasks.Task<Microsoft.OData.Mcp.Authentication.Outbound.TokenEndpointResponse> AcquireAsync(Microsoft.OData.Mcp.Authentication.Outbound.AuthorizationServerMetadata metadata, string clientId, string clientSecret, string scope, System.Uri resource, System.Threading.CancellationToken cancellationToken)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `metadata` | `Microsoft.OData.Mcp.Authentication.Outbound.AuthorizationServerMetadata` | The authorization server metadata whose `token_endpoint` is posted to. |
| `clientId` | `string` | The confidential client identifier. |
| `clientSecret` | `string` | The client secret; never logged. |
| `scope` | `string?` | The space-delimited scope to request, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) to request none. |
| `resource` | `System.Uri?` | The RFC 8707 resource indicator, sent exactly as it was published or configured, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) when the request sends none. |
| `cancellationToken` | `System.Threading.CancellationToken` | The token that cancels the request. |

#### Returns

Type: `System.Threading.Tasks.Task<Microsoft.OData.Mcp.Authentication.Outbound.TokenEndpointResponse>`
The successful token response, which normally carries no refresh token.

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | Thrown when *metadata* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |
| `ArgumentException` | Thrown when *clientId* or *clientSecret* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null), empty, or whitespace. |
| `InvalidOperationException` | Thrown when *metadata* carries no token endpoint. |
| `OAuthTokenException` | Thrown when the authorization server rejects the credentials — `invalid_client` — or when the
request fails at the transport. |

#### Examples

```csharp
try
{
    var response = await grant.AcquireAsync(metadata, clientId, clientSecret, scope, resource, cancellationToken);
}
catch (OAuthTokenException ex) when (ex.Error == "invalid_client")
{
    // ODATA_MCP_CLIENT_SECRET is wrong or the client is not registered.
}
```

first one did.
