## Summary

Everything the outbound OAuth discovery algorithm learned about a protected OData service: the
`WWW-Authenticate` challenge it started from, the RFC 9728 protected resource metadata it found (if
any), the authorization server it selected, and the grants, scope, and RFC 8707 resource a grant needs.

## Remarks

Produced exclusively by [CancellationToken)](https://learn.microsoft.com/dotnet/api/microsoft.odata.mcp.authentication.outbound.oauthdiscovery.discoverasync(system.uri,system.collections.generic.ireadonlylist{system.string},system.int32,system.uri,system.uri,system.threading.cancellationtoken)),
which never returns an instance without an authorization server: discovery fails first rather than
handing a caller a half-populated result. Per `AUTH-13` the challenge `client_id` is reachable
only as [OAuthChallenge.ResourceClientId](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/OAuthChallenge#resourceclientid) through [OAuthDiscoveryResult.Challenge](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/OAuthDiscoveryResult#challenge), so nothing on this
type can be mistaken for the client id this process authenticates with.

## Examples

```csharp
var result = await discovery.DiscoverAsync(serviceRoot, wwwAuthenticate, 401, null, null, cancellationToken);

Console.WriteLine(result.AuthorizationServer.TokenEndpoint);
Console.WriteLine(result.Resource);
if (result.AdvertisedGrants.Contains(ODataMcpAuthConstants.DeviceCodeGrantType))
{
    // Start a device code grant against result.AuthorizationServer.
}
```

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Resource

Gets the RFC 8707 resource indicator a token request should ask for, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) when
no token request should carry one.

#### Syntax

```csharp
public System.Uri Resource { get; }
```

#### Property Value

Type: `System.Uri?`

#### Remarks

Resolved per step 8b of the discovery algorithm: the protected resource metadata `resource` when
it is absolute, else the operator's `--resource`, else [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). There is
deliberately no origin fallback: RFC 8707 `resource` is only meaningful when the resource itself
published it or the operator named it, and an invented audience is rejected by strict authorization
servers that would otherwise have honored `scope` alone.
