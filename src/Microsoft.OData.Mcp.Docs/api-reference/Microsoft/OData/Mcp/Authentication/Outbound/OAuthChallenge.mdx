## Summary

One parsed `WWW-Authenticate` challenge: the authentication scheme, the OAuth-relevant auth-params
promoted to typed properties, and the complete, case-insensitive parameter set exactly as it arrived.

## Remarks

Instances are produced by [WwwAuthenticateParser](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/WwwAuthenticateParser) and are immutable once created.
[OAuthChallenge.ResourceClientId](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/OAuthChallenge#resourceclientid) carries the challenge `client_id`, which is the &lt;em&gt;resource&lt;/em&gt;
application id (Microsoft Graph advertises
[ODataMcpAuthConstants.MicrosoftGraphResourceAppId](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/ODataMcpAuthConstants#microsoftgraphresourceappid)). It is never our public client id and
must never be copied onto an outbound OAuth client id; that is why no member of this type is named
`ClientId`.

## Examples

```csharp
var challenge = WwwAuthenticateParser.SelectBearer(WwwAuthenticateParser.ParseAll(result.WwwAuthenticate));
if (challenge is not null &amp;&amp; challenge.ResourceMetadata is not null)
{
    // Fetch RFC 9728 protected resource metadata from challenge.ResourceMetadata.
}
```
