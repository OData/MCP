## Summary

Supplies the enterprise OpenID Connect id token the identity assertion grant exchanges, reading it from
the file `--idp-id-token-file` names or from the
[ODataMcpAuthConstants.IdTokenEnvironmentVariable](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/ODataMcpAuthConstants#idtokenenvironmentvariable) environment variable.

## Remarks

Per `specs/v3/AUTHENTICATION.md` "Grants → Identity Assertion Grant" the id token is never passed on
argv: a process list is world-readable on every platform this tool ships to, and an id token is a bearer
credential for the end user's enterprise identity. The file is re-read on every call rather than cached,
so a daemon whose sidecar rotates the token picks the new one up without a restart, and per
`AUTH-12` nothing here ever logs, elicits, or echoes the token itself — only the path it came from.

## Examples

```csharp
var callback = new FileIdTokenCallback(options.IdpIdTokenFile);

var providerOptions = new IdentityAssertionGrantProviderOptions
{
    ClientId = options.ClientId,
    IdpClientId = options.IdpClientId,
    IdTokenCallback = callback.ReadAsync
};
```

### <Icon icon="function" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> ReadAsync

Reads the id token, preferring the configured file over the environment variable.

#### Syntax

```csharp
public System.Threading.Tasks.Task<string> ReadAsync(ModelContextProtocol.Authentication.IdentityAssertionGrantContext context, System.Threading.CancellationToken cancellationToken)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `context` | `ModelContextProtocol.Authentication.IdentityAssertionGrantContext` | The resource and authorization server URLs the SDK discovered, unused by this source. |
| `cancellationToken` | `System.Threading.CancellationToken` | The token that cancels the file read. |

#### Returns

Type: `System.Threading.Tasks.Task<string>`
The trimmed id token.

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `InvalidOperationException` | Thrown when the configured file does not exist, when it is empty, or when neither a file nor
[ODataMcpAuthConstants.IdTokenEnvironmentVariable](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/ODataMcpAuthConstants#idtokenenvironmentvariable) supplies a token. |

#### Examples

```csharp
SdkAuth.IdentityAssertionGrantIdTokenCallback callback = new FileIdTokenCallback(path).ReadAsync;
```

#### Remarks

The token is trimmed because both sources routinely pick up a trailing newline — a shell
redirection, a Kubernetes projected volume — and a JWT with a newline on the end is rejected by
every token endpoint with an error that says nothing about whitespace. Failures name the source,
never the value.
