## Summary

Resolves the space-delimited OAuth `scope` a token request should ask for, per step 8 of the
discovery algorithm and matching the SDK 2.2 `ScopeSelectorDelegate` order exactly.

## Remarks

Per Key Decision 9 of `specs/v3/AUTHENTICATION.md`, the base scope order is: the
`WWW-Authenticate` challenge `scope`, then RFC 9728 protected resource metadata
`scopes_supported`, then the operator's `--scopes`, then no scope at all.
`offline_access` is appended whenever the authorization server or protected resource metadata
advertises it, or the authorization server advertises the `refresh_token` grant, so an interactive
grant can refresh instead of re-prompting. Finally, [OutboundOAuthOptions.ScopeSelector](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/OutboundOAuthOptions#scopeselector) — the
SDK's `ScopeSelectorDelegate` reused as-is — runs last and may remove
`offline_access`, which this type logs a warning about rather than silently accepting.

## Examples

```csharp
var resolver = new ScopeResolver(logger);
var scope = resolver.Resolve(discovery, options);

var device = await deviceCodeGrant.StartAsync(discovery.AuthorizationServer, clientId, scope, discovery.Resource, cancellationToken);
```

#### Syntax


#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `discovery` | `Microsoft.OData.Mcp.Authentication.Outbound.OAuthDiscoveryResult` | The discovery result whose challenge scope, protected resource metadata, and authorization server are consulted. |
| `options` | `Microsoft.OData.Mcp.Authentication.Outbound.OutboundOAuthOptions` | The operator's outbound OAuth settings, carrying the `--scopes` fallback and an optional scope selector. |

#### Returns

Type: `string?`
The resolved space-delimited scope, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) when nothing resolves to a non-empty
scope.

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | Thrown when *discovery* or *options* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |

#### Examples

```csharp
var scope = resolver.Resolve(discovery, options); // "openid offline_access", or null
```

#### Remarks

[OutboundOAuthOptions.ScopeSelector](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/OutboundOAuthOptions#scopeselector) receives the individual scope tokens as an
[IReadOnlyCollection`1](https://learn.microsoft.com/dotnet/api/system.collections.generic.ireadonlycollection-1) — exactly the SDK 2.2 `ScopeSelectorDelegate`
signature — and its returned scopes are re-joined with single spaces.
