## Summary

Fetches an RFC 9728 protected resource metadata document over the handler-free `"OAuth"` named
[HttpClient](https://learn.microsoft.com/dotnet/api/system.net.http.httpclient), treating every well-known failure per `AUTH-14`: 401, 403, 404, and a
failed parse are logged and swallowed; a timeout or 5xx is retried once before it becomes fatal.

## Remarks

A new `"OAuth"` client is requested from [IHttpClientFactory](https://learn.microsoft.com/dotnet/api/system.net.http.ihttpclientfactory) on every call rather than
cached, matching the "Two named HttpClients" table in `specs/v3/AUTHENTICATION.md`: this client
carries no delegating handler and is safe to create per request. Response bodies are never logged.

## Examples

```csharp
var client = new ProtectedResourceMetadataClient(httpClientFactory, logger);
var metadata = await client.TryGetAsync(new Uri("https://api.example.com/.well-known/oauth-protected-resource"), cancellationToken);
if (metadata is not null &amp;&amp; metadata.AuthorizationServers?.Count &gt; 0)
{
    // Continue discovery against metadata.AuthorizationServers[0].
}
```
