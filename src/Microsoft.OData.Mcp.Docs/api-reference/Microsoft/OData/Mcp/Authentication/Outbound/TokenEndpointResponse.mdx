## Summary

The RFC 6749 section 5.1 successful token response returned from a token endpoint.

## Remarks

Deserialized exclusively through [OutboundOAuthJsonContext](https://learn.microsoft.com/dotnet/api/microsoft.odata.mcp.authentication.outbound.outboundoauthjsoncontext) (AOT: JSON source-gen; no
reflection). This is the RFC 6749 wire shape only; it is &lt;em&gt;not&lt;/em&gt; the SDK `TokenContainer`
cache/runtime format, which is PascalCase and additionally carries `ObtainedAt`.
[String)](https://learn.microsoft.com/dotnet/api/microsoft.odata.mcp.authentication.outbound.tokenendpointresponse.totokencontainer(system.string,system.string,system.string,system.string,system.string)) is the single place that
conversion happens.

## Examples

```csharp
var response = JsonSerializer.Deserialize(json, OutboundOAuthJsonContext.Default.TokenEndpointResponse);
var container = response!.ToTokenContainer(
    previousRefreshToken: null,
    clientId: "cli",
    clientSecret: null,
    authorizationServer: metadata.Issuer!,
    tokenEndpointAuthMethod: TokenEndpointClient.AuthMethodNone);
```

### <Icon icon="function" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> ToTokenContainer

Maps this wire response onto the SDK `TokenContainer` the cache and the outbound
handler read, stamping `ObtainedAt` at the moment of the call.

#### Syntax

```csharp
public ModelContextProtocol.Authentication.TokenContainer ToTokenContainer(string previousRefreshToken, string clientId, string clientSecret, string authorizationServer, string tokenEndpointAuthMethod)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `previousRefreshToken` | `string?` | The refresh token the caller already holds, kept when this response omits one; or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) when there is none. |
| `clientId` | `string?` | The client identifier the tokens were issued to, persisted so a cold start can refresh without re-registering. |
| `clientSecret` | `string?` | The client secret, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) for a public client. |
| `authorizationServer` | `string` | The issuer the tokens came from. |
| `tokenEndpointAuthMethod` | `string?` | The token endpoint authentication method the grant used, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) when none applies. |

#### Returns

Type: `ModelContextProtocol.Authentication.TokenContainer`
A container carrying this response's access token, lifetime, and scope, the effective refresh token,
and the client and server identity the caller supplied.

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentException` | Thrown when *authorizationServer* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null), empty, or whitespace. |
| `InvalidOperationException` | Thrown when [TokenEndpointResponse.AccessToken](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/TokenEndpointResponse#accesstoken) is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null), empty, or whitespace. |

#### Examples

```csharp
var refreshed = response.ToTokenContainer(
    previousRefreshToken: current.RefreshToken,
    clientId: current.ClientId,
    clientSecret: current.ClientSecret,
    authorizationServer: current.AuthorizationServer!,
    tokenEndpointAuthMethod: current.TokenEndpointAuthMethod);
```

#### Remarks

RFC 6749 section 6 makes `refresh_token` optional on a refresh response, so an omitted value
means "keep the one you have", never "you no longer have one"; that rule lives here so no grant has
to remember it. An absent `token_type` becomes
[ODataMcpAuthConstants.BearerScheme](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/ODataMcpAuthConstants#bearerscheme), because the SDK container requires one and every
grant this package implements is a bearer grant.
