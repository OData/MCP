## Summary

What an API publishes about how to sign in to it: the RFC 8414 authorization servers that issue
its tokens, the scopes a client should ask for, and which route bases the published document covers.

## Remarks

Nothing here describes how the API validates a token. That stays with whatever authentication handler
the app already registered; this type only describes the API to a client that has not signed in yet.
The default route base is the application root, which is the usual shape of an API that is not sharing
a host with MVC.

## Examples

```csharp
builder.Services.AddProtectedResourceMetadata(options =&gt;
{
    options.AuthorizationServers.Add(new Uri("https://login.microsoftonline.com/contoso.com/v2.0"));
    options.ScopesSupported.Add("api://contoso-odata/Data.Read");
    options.ResourceName = "Contoso API";
});
```

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> AnnotateChallenges

Gets or sets a value indicating whether a `401` under a covered route base has its
`WWW-Authenticate` challenge rewritten to carry `resource_metadata`.

#### Syntax

```csharp
public bool AnnotateChallenges { get; set; }
```

#### Property Value

Type: `bool`
Defaults to [`true`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool).

#### Remarks

Turn this off only when the app already emits an RFC 9728 hint of its own. A client that never sees
`resource_metadata` still finds the document through the two well-known URLs, but it spends an
extra request doing so.

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> AuthorizationServers

Gets the RFC 8414 issuer URLs of the authorization servers that issue tokens for this API, in the
order a client should try them.

#### Syntax

```csharp
public System.Collections.Generic.List<System.Uri> AuthorizationServers { get; }
```

#### Property Value

Type: `System.Collections.Generic.List<System.Uri>`
At least one entry is required. Each must be absolute and `https`; `http` is accepted only
for loopback hosts so a test or a local identity provider still works.

#### Examples

```csharp
options.AuthorizationServers.Add(new Uri("https://login.microsoftonline.com/contoso.com/v2.0"));
```

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Prefixes

Gets the route bases the published documents cover, in the same form Endpoint Routing and Minimal
APIs accept.

#### Syntax

```csharp
public System.Collections.Generic.List<string> Prefixes { get; }
```

#### Property Value

Type: `System.Collections.Generic.List<string>`
Empty by default, which means the application root only. A non-empty list replaces that default.

#### Examples

```csharp
options.Prefixes.Add("");
options.Prefixes.Add("odata");
options.Prefixes.Add("api/v1");
```

#### Remarks

An empty string and `/` are the application root, matching `MapGroup("")` and
`AddRouteComponents(string.Empty, model)`. `odata` and `/odata/` both mean the
`/odata` base. Nested bases such as `api/v1` are valid. A whitespace-only entry is
rejected by [ProtectedResourceMetadataOptions.Validate](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ProtectedResourceMetadataOptions#validate): it is not a route base.

#### Examples

```csharp

options.Validate();
```

#### Remarks

Called by [ProtectedResourceMetadataStartupFilter](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ProtectedResourceMetadataStartupFilter) before the pipeline is built, so a
misconfigured API refuses to start rather than serving a document that sends every client to an
authorization server that does not exist. An empty string and `/` in [ProtectedResourceMetadataOptions.Prefixes](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ProtectedResourceMetadataOptions#prefixes)
are the application root and pass.
