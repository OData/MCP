## Summary

What an OData API publishes about how to sign in to it: the RFC 8414 authorization servers that issue
its tokens, the scopes a client should ask for, and which route prefixes the published document covers.

## Remarks

Nothing here describes how the API validates a token. That stays with whatever authentication handler
the app already registered; this type only describes the API to a client that has not signed in yet.

## Examples

```csharp
builder.Services.AddODataProtectedResource(options =&gt;
{
    options.AuthorizationServers.Add(new Uri("https://login.microsoftonline.com/contoso.com/v2.0"));
    options.ScopesSupported.Add("api://contoso-odata/Data.Read");
    options.ResourceName = "Contoso OData";
});
```

Gets or sets a value indicating whether a `401` under a covered prefix has its
`WWW-Authenticate` challenge rewritten to carry `resource_metadata`.

#### Syntax

```csharp
public bool AnnotateChallenges { get; set; }
```

#### Property Value

Type: `bool`
Defaults to [`true`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool).

#### Remarks

Turn this off only when the app already emits an RFC 9728 hint of its own. A client that never sees
`resource_metadata` still finds the document through the two well-known URLs, but it spends an
extra request doing so.

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> AuthorizationServers

Gets the RFC 8414 issuer URLs of the authorization servers that issue tokens for this API, in the
order a client should try them.

#### Syntax

```csharp
public System.Collections.Generic.List<System.Uri> AuthorizationServers { get; }
```

#### Property Value

Type: `System.Collections.Generic.List<System.Uri>`
At least one entry is required. Each must be absolute and `https`; `http` is accepted only
for loopback hosts so a test or a local identity provider still works.

#### Examples

```csharp
options.AuthorizationServers.Add(new Uri("https://login.microsoftonline.com/contoso.com/v2.0"));
```

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Prefixes

Gets the OData route prefixes the published documents cover, without leading or trailing slashes.

#### Syntax

```csharp
public System.Collections.Generic.List<string> Prefixes { get; }
```

#### Property Value

Type: `System.Collections.Generic.List<string>`
Empty by default, which means the prefixes come from
[ODataMcpHostOptions)](https://learn.microsoft.com/dotnet/api/microsoft.odata.mcp.aspnetcore.hosting.odatamcproutediscovery.discover(system.iserviceprovider,microsoft.odata.mcp.aspnetcore.hosting.odatamcphostoptions)) on the first
request. A non-empty list replaces discovery outright.

#### Examples

```csharp
options.Prefixes.Add("odata");
```

#### Remarks

Set this only when the routing table cannot be read for a prefix — a hand-rolled OData host, or a
reverse proxy that rewrites the path. A blank entry is rejected by [ODataProtectedResourceOptions.Validate](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ODataProtectedResourceOptions#validate): an
OData service mounted at the application root is discovered as the empty prefix on its own, so a
blank entry here is a typo rather than a configuration.

#### Examples

```csharp

```

#### Remarks

Called by [ODataProtectedResourceStartupFilter](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ODataProtectedResourceStartupFilter) before the pipeline is built, so a
misconfigured API refuses to start rather than serving a document that sends every client to an
authorization server that does not exist.
