## Types

### <Icon icon="file-brackets-curly" iconType="duotone" color="#419AC5" size={24} style={{ paddingRight: '8px' }} /> Classes

| Name | Summary |
| ---- | ------- |
| [ProtectedResourceMetadataMiddleware](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ProtectedResourceMetadataMiddleware) | Publishes RFC 9728 protected resource metadata for the configured route bases, and rewrites the  `WWW-Authenticate` challenge on a `401` beneath one of those bases so a client is told  where that document lives. |
| [ProtectedResourceMetadataOptions](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ProtectedResourceMetadataOptions) | What an API publishes about how to sign in to it: the RFC 8414 authorization servers that issue  its tokens, the scopes a client should ask for, and which route bases the published document covers. |
| [ProtectedResourceMetadataStartupFilter](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ProtectedResourceMetadataStartupFilter) | Validates [ProtectedResourceMetadataOptions](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ProtectedResourceMetadataOptions) at startup and prepends  [ProtectedResourceMetadataMiddleware](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ProtectedResourceMetadataMiddleware) to the pipeline, no matter how the app wrote its own  `Configure` delegate. |
