## Types

### <Icon icon="file-brackets-curly" iconType="duotone" color="#419AC5" size={24} style={{ paddingRight: '8px' }} /> Classes

| Name | Summary |
| ---- | ------- |
| [ODataProtectedResourceMiddleware](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ODataProtectedResourceMiddleware) | Publishes RFC 9728 protected resource metadata for every OData route prefix the app serves, and rewrites  the `WWW-Authenticate` challenge on a `401` beneath one of those prefixes so a client is told  where that document lives. |
| [ODataProtectedResourceOptions](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ODataProtectedResourceOptions) | What an OData API publishes about how to sign in to it: the RFC 8414 authorization servers that issue  its tokens, the scopes a client should ask for, and which route prefixes the published document covers. |
| [ODataProtectedResourceStartupFilter](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ODataProtectedResourceStartupFilter) | Validates [ODataProtectedResourceOptions](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ODataProtectedResourceOptions) at startup and prepends  [ODataProtectedResourceMiddleware](/api-reference/Microsoft/OData/Mcp/AspNetCore/Authentication/ODataProtectedResourceMiddleware) to the pipeline, no matter how the app wrote its own  `Configure` delegate. |
