## Methods

### <Icon icon="function" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> AddRoute

Registers an explicit *prefix* and *model* when the routing table
            does not carry an [IEdmModel](https://learn.microsoft.com/dotnet/api/microsoft.odata.edm.iedmmodel) (for example a custom host that never wrote OData metadata).

#### Syntax

```csharp
public Microsoft.OData.Mcp.AspNetCore.Hosting.ODataMcpHostOptions AddRoute(string prefix, Microsoft.OData.Edm.IEdmModel model)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `prefix` | `string` | The OData route prefix, for example `odata`. Empty is the application root. |
| `model` | `Microsoft.OData.Edm.IEdmModel` | The EdmLib model for that prefix. |

#### Returns

Type: `Microsoft.OData.Mcp.AspNetCore.Hosting.ODataMcpHostOptions`
The same options instance.

#### Examples

```csharp
builder.Services.AddODataMcp(options =&gt;
{
    options.AddRoute("odata", GetEdmModel());
});
```

#### Remarks

Discovery from `EndpointDataSource` still runs and wins when it finds the same prefix.
