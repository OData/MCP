## Summary

[IHttpContextAccessor](https://learn.microsoft.com/dotnet/api/microsoft.aspnetcore.http.ihttpcontextaccessor) that keeps the MCP request and the in-process OData
request as two contexts. [McpHttpContextAccessor.HttpContext](/api-reference/Microsoft/OData/Mcp/AspNetCore/Hosting/McpHttpContextAccessor#httpcontext) always returns [McpHttpContextAccessor.Active](/api-reference/Microsoft/OData/Mcp/AspNetCore/Hosting/McpHttpContextAccessor#active).
[HttpContext)](https://learn.microsoft.com/dotnet/api/microsoft.odata.mcp.aspnetcore.hosting.mcphttpcontextaccessor.start(microsoft.aspnetcore.http.httpcontext)) / [McpHttpContextAccessor.End](/api-reference/Microsoft/OData/Mcp/AspNetCore/Hosting/McpHttpContextAccessor#end) change which context is active without using
Microsoft's `HttpContextAccessor` setter (that setter nulls a shared holder and ends
the outer request).

## Remarks

Register this as [IHttpContextAccessor](https://learn.microsoft.com/dotnet/api/microsoft.aspnetcore.http.ihttpcontextaccessor) after `AddHttpContextAccessor` so
last-wins DI gives Restier and `DefaultHttpContextFactory` this instance.

Host `Initialize` assigns [McpHttpContextAccessor.HttpContext](/api-reference/Microsoft/OData/Mcp/AspNetCore/Hosting/McpHttpContextAccessor#httpcontext) (sets [McpHttpContextAccessor.Outer](/api-reference/Microsoft/OData/Mcp/AspNetCore/Hosting/McpHttpContextAccessor#outer) and
[McpHttpContextAccessor.Active](/api-reference/Microsoft/OData/Mcp/AspNetCore/Hosting/McpHttpContextAccessor#active)). Inner execute calls [HttpContext)](https://learn.microsoft.com/dotnet/api/microsoft.odata.mcp.aspnetcore.hosting.mcphttpcontextaccessor.start(microsoft.aspnetcore.http.httpcontext)), then [McpHttpContextAccessor.End](/api-reference/Microsoft/OData/Mcp/AspNetCore/Hosting/McpHttpContextAccessor#end) in
`finally`. Host `Dispose` assigns [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null), which poisons the
holder so every execution context sees request-end.

## Examples

```csharp
accessor.HttpContext = mcpRequest;
accessor.Start(odataRequest);
try
{
    await pipeline(odataRequest);
}
finally
{
    accessor.End();
}
```
