## Summary

Configures OData MCP Tasks on `AddODataMcp`. Hosts call
[IMcpTaskStore)](https://learn.microsoft.com/dotnet/api/microsoft.odata.mcp.aspnetcore.hosting.odatamcpserverbuilder.withtasks(modelcontextprotocol.extensions.tasks.imcptaskstore)) and [WaitForAnnotatedAction``1](https://learn.microsoft.com/dotnet/api/microsoft.odata.mcp.aspnetcore.hosting.odatamcpserverbuilder.waitforannotatedaction`-1) here, not on
`UseODataMcp` and not via SDK `WithTasks` from app code.

## Examples

```csharp
builder.Services.AddODataMcp(options =&gt; { }, mcp =&gt;
{
    mcp.WithTasks(new InMemoryMcpTaskStore());
    mcp.WaitForAnnotatedAction&lt;HostAuthorizeWaiter&gt;();
});
```

### <Icon icon="function" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> WithTasks

Enables MCP Tasks for annotated actions only. CRUD, functions, and unannotated
actions stay one-shot.

#### Syntax

```csharp
public Microsoft.OData.Mcp.AspNetCore.Hosting.ODataMcpServerBuilder WithTasks(ModelContextProtocol.Extensions.Tasks.IMcpTaskStore store)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `store` | `ModelContextProtocol.Extensions.Tasks.IMcpTaskStore` | The protocol task store. Register a singleton; stateless HTTP
creates a fresh server per POST. |

#### Returns

Type: `Microsoft.OData.Mcp.AspNetCore.Hosting.ODataMcpServerBuilder`
This builder.

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | Thrown when *store* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |

#### Remarks

Wires `tasks/get`, `tasks/update`, and `tasks/cancel` from
`ModelContextProtocol.Extensions.Tasks`. Does not wrap every catalog tool:
the execution-mode selector returns Optional only for annotated actions.
