## Summary

Captures the application `RequestDelegate` when MCP is on so tool calls can invoke
routing in-process instead of looping back through the server.

## Remarks

Registered by `AddODataMcp` because [IStartupFilter](https://learn.microsoft.com/dotnet/api/microsoft.aspnetcore.hosting.istartupfilter) must be in DI before
`Build()`. Capture always runs so it can wrap the app's `Configure` (including
`UseODataMcp`). Execution still requires [ODataMcpPipeline.IsEnabled](/api-reference/Microsoft/OData/Mcp/AspNetCore/Hosting/ODataMcpPipeline#isenabled).
