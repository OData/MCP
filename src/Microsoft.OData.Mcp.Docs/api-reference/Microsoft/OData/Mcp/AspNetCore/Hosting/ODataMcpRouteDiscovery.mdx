## Summary

Discovers `(prefix, IEdmModel)` pairs from ASP.NET Core endpoint routing without compiling against
Microsoft.AspNetCore.OData 7 or 8.

## Methods

### <Icon icon="thumbtack" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Discover

Discovers OData prefixes and models from explicit registration, endpoint metadata, OData 7/Restier
catch-all routes, and (when present) an already-loaded OData options dictionary.

public static System.Collections.Generic.IReadOnlyList<Microsoft.OData.Mcp.AspNetCore.Hosting.ODataMcpRouteBinding> Discover(System.IServiceProvider services, Microsoft.OData.Mcp.AspNetCore.Hosting.ODataMcpHostOptions options)

#### Returns

Type: `System.Collections.Generic.IReadOnlyList<Microsoft.OData.Mcp.AspNetCore.Hosting.ODataMcpRouteBinding>`
Bindings after include/exclude filters. Duplicate prefixes keep the last discovered model.
