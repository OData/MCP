## Summary

Copies declared [IEdmModel](https://learn.microsoft.com/dotnet/api/microsoft.odata.edm.iedmmodel) members into the Core EDM projection.
CLR properties ignored on the OData model are never copied.

### <Icon icon="thumbtack" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> ToCsdlXml

Serializes an [IEdmModel](https://learn.microsoft.com/dotnet/api/microsoft.odata.edm.iedmmodel) to a CSDL XML document, the same representation the
service returns from `$metadata`.

#### Syntax

```csharp
public static string ToCsdlXml(Microsoft.OData.Edm.IEdmModel model)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `model` | `Microsoft.OData.Edm.IEdmModel` | The ASP.NET Core OData model. |

#### Returns

Type: `string?`
The CSDL XML, or `null` when the model cannot be written (the writer reports validation errors).

#### Remarks

In-process hosts do not fetch `$metadata` over HTTP, so this is how the
`odata://{prefix}/$metadata` MCP resource gets its text. A `null` result leaves that resource
empty rather than failing session construction.
