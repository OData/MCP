| [AddCommand](/api-reference/Microsoft/OData/Mcp/Tools/Commands/AddCommand) | Interactive wizard command that generates the `claude mcp add` registration line for a remote OData  service, including the outbound OAuth flags `odata-mcp start` needs to sign in. |

| [TryCommand](/api-reference/Microsoft/OData/Mcp/Tools/Commands/TryCommand) | `odata-mcp try &lt;url&gt;`: probe a service before committing to it. Fetches `$metadata`, reads one row  from the first entity set, says which of the two is secured, checks the row against the model, and prints a  verdict. With auth flags it probes again through the authenticating client; without them, on a 401 it runs  OAuth discovery and prints what it found. |
