## Summary

Everything the `odata-mcp add` wizard collected about how the generated `start` command should
authenticate.

## Remarks

Per `AUTH-5` this is a top-level type rather than a tuple or a nested class, because it crosses
three methods — the prompts that fill it, the connection test that turns it into
[OutboundOAuthOptions](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/OutboundOAuthOptions), and the command builder that turns it into flags.

There is deliberately no client secret property. Per `specs/v3/AUTHENTICATION.md` the wizard never
writes a client secret into MCP configuration at all: it prints an instruction to set
[ODataMcpAuthConstants.ClientSecretEnvironmentVariable](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/ODataMcpAuthConstants#clientsecretenvironmentvariable) in the environment that launches the
host, which `start` reads. [AddCommandAuthSettings.ApiKey](/api-reference/Microsoft/OData/Mcp/Tools/Commands/AddCommandAuthSettings#apikey), [AddCommandAuthSettings.BasicPassword](/api-reference/Microsoft/OData/Mcp/Tools/Commands/AddCommandAuthSettings#basicpassword), and
[AddCommandAuthSettings.AuthToken](/api-reference/Microsoft/OData/Mcp/Tools/Commands/AddCommandAuthSettings#authtoken)&lt;em&gt;are&lt;/em&gt; written, and each is warned about when it is.

## Examples

```csharp
var settings = new AddCommandAuthSettings
{
    ClientId = "00000000-0000-0000-0000-000000000000",
    Grant = OutboundGrantKind.DeviceCode,
    Scopes = "https://graph.microsoft.com/.default"
};

var command = wizard.BuildMcpCommand("graph", url, settings, "user", verbose: false);
```

### <Icon icon="function" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> ToOutboundOptions

Turns these settings into the outbound options the `start` command would build from the same
flags, so a connection test exercises the real authentication path rather than a simplified one.

#### Syntax

```csharp
public Microsoft.OData.Mcp.Authentication.Outbound.OutboundOAuthOptions ToOutboundOptions()
```

#### Returns

Type: `Microsoft.OData.Mcp.Authentication.Outbound.OutboundOAuthOptions`
The options, with [ODataMcpAuthConstants.ClientSecretEnvironmentVariable](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/ODataMcpAuthConstants#clientsecretenvironmentvariable) and
[ODataMcpAuthConstants.IdTokenEnvironmentVariable](/api-reference/Microsoft/OData/Mcp/Authentication/Outbound/ODataMcpAuthConstants#idtokenenvironmentvariable) already folded in.

#### Examples

```csharp
using var host = await ToolsMcpHost.CreateAsync(url, settings.ToOutboundOptions(), false, false, null, ct);
```

#### Remarks

The environment is read here for the same reason `start` reads it: a client credentials test
that ignored `ODATA_MCP_CLIENT_SECRET` would fail for a reason the operator has already been
told how to fix.
