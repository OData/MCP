## Summary

A mutable slot for the one [ODataMcpSession](/api-reference/Microsoft/OData/Mcp/Core/Catalog/ODataMcpSession) a Tools host serves, registered before the host
is built and filled once `$metadata` has been fetched and parsed.

## Remarks

The session cannot be registered directly because building it requires the very
[IHttpClientFactory](https://learn.microsoft.com/dotnet/api/system.net.http.ihttpclientfactory) the host owns: the metadata GET runs through the
authenticating `"OData"` client, which only exists after `Build()`, and a service collection is
frozen from that moment on. This holder is what lets one host serve both sides of that ordering.

## Examples

```csharp
builder.Services.AddSingleton&lt;ToolsMcpSessionHolder&gt;();
builder.Services.AddMcpServer().WithODataCatalogHandlers(sp =&gt;
{
    var session = sp.GetRequiredService&lt;ToolsMcpSessionHolder&gt;().Session;
    ArgumentNullException.ThrowIfNull(session);

    return session;
});
```
