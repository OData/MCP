## Summary

Names JSON properties on an action result that are URLs to elicit. After OData routes
are mapped, the host stamps `Microsoft.OData.Mcp.V1.ElicitUrlProperties` on the
matching EDM action.

## Remarks

Pair with [McpTaskAttribute](/api-reference/Microsoft/OData/Mcp/Core/Vocabularies/McpTaskAttribute). Convention ModelBuilder hosts use
`HasMcpElicitUrl` instead. When this term is omitted, the runtime elicits the
default names in [McpVocabulary.DefaultElicitUrlProperties](/api-reference/Microsoft/OData/Mcp/Core/Vocabularies/McpVocabulary#defaulteliciturlproperties) if they appear
on the Started JSON. Functions are not elicited.

## Examples

```csharp
[BoundOperation(OperationType = OperationType.Action)]
[McpTask]
[McpElicitUrl("connectUri")]
public AuthorizationTicket Authorize(IntegrationConnection connection)
{
    return ticket;
}
```
