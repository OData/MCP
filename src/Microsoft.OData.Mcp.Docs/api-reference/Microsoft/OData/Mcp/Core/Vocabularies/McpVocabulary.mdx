## Summary

Identifiers and CSDL for the `Microsoft.OData.Mcp.V1` vocabulary.

## Remarks

Core ships the vocabulary document so the CSDL parser and the Tools host can read
`Task` / `ElicitUrlProperties` from remote `$metadata`. AspNetCore loads the
same XML into EdmLib when a host stamps those terms onto an `IEdmModel`.
