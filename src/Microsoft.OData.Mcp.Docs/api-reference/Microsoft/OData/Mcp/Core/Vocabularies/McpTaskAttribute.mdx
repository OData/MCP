## Summary

Marks a CLR operation as an MCP task. After OData routes are mapped, the host stamps
`Microsoft.OData.Mcp.V1.Task` on the matching EDM action.

## Remarks

Pair with Restier `[BoundOperation]` / `[UnboundOperation]` or an OData controller action.
Convention ModelBuilder hosts use `HasMcpTask()` instead. Pair
[McpElicitUrlAttribute](/api-reference/Microsoft/OData/Mcp/Core/Vocabularies/McpElicitUrlAttribute) to name elicit URL properties without relying on the
constructor convenience arguments. Functions are not tasked.

## Examples

```csharp
[BoundOperation(OperationType = OperationType.Action)]
[McpTask]
public Order Ship(Order order)
{
    return order;
}
```
