## Summary

Closed AOT reader for the compact `Form` / `Field` / `Option` island
nested under `Microsoft.OData.Mcp.V1.ElicitForm`.

## Remarks

Same grammar as McpEssentials `FormXml`. Core does not reference McpEssentials.
Readers match [LocalName](https://learn.microsoft.com/dotnet/api/system.xml.xmlreader.localname) only. DTD processing is prohibited.
