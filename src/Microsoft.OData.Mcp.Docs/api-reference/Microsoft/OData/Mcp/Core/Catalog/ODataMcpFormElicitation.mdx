## Summary

Before-invoke form elicitation: client gate, MRTR, merge, decline.

## Remarks

Tools (remote `$metadata`) uses this before invoke with [ElicitFormMapper](/api-reference/Microsoft/OData/Mcp/Core/Catalog/ElicitFormMapper).
In-process AspNetCore actions call `RequireForm`. Schema `default` is the form
author's; the harness may pre-fill the widget from tool arguments.
