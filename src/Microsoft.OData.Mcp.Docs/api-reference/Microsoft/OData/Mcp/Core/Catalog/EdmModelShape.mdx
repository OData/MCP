## Summary

Renders the whole-service map behind `odata_describe_model`: a summary of sets and navigations, a complete
dump of every in-scope type, a relationship-only mermaid diagram, and the unbound operation list.

## Remarks

This is the context-sized stand-in for `$metadata`. Every shape is composed from the cached
[EdmTypeShape](/api-reference/Microsoft/OData/Mcp/Core/Catalog/EdmTypeShape) instances so `odata_describe_type`, type cards, and the model map never disagree.
