## Summary

Validates tool payloads against the declared EDM before any OData HTTP is sent, and formats values for the wire.

## Remarks

This is how the first `tools/call` becomes the right one: a wrong JSON kind, an unknown property, a missing
required-on-create value, an enum member that does not exist, or a string over `MaxLength` is reported with
the declared shape instead of a round trip to the service. Every rule here is OPTIMIZATION.md §4 and §5.

### <Icon icon="thumbtack" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> ValidateEntityBody

```csharp
public static string ValidateEntityBody(Microsoft.OData.Mcp.Core.Models.EdmModel model, Microsoft.OData.Mcp.Core.Catalog.ODataMcpCatalogOptions options, Microsoft.OData.Mcp.Core.Catalog.EdmTypeShape shape, System.Text.Json.JsonElement body, bool isCreate)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `model` | `Microsoft.OData.Mcp.Core.Models.EdmModel` | The Core EDM. |
| `options` | `Microsoft.OData.Mcp.Core.Catalog.ODataMcpCatalogOptions` | Catalog options (required-on-create enforcement, enum wire format). |
| `shape` | `Microsoft.OData.Mcp.Core.Catalog.EdmTypeShape` | The target type's shape. |
| `body` | `System.Text.Json.JsonElement` | The parsed JSON object. |
| `isCreate` | `bool` | `true` for POST, which also checks required-on-create; `false` for PATCH. |

#### Returns

Type: `string?`
`null` when the body is valid; otherwise the message the caller returns as a tool error.

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | Thrown when *model*, *options*, or *shape* is null. |

#### Remarks

Checks, in order: required-on-create (POST only, unless [ODataMcpCatalogOptions.EnforceRequiredOnCreate](/api-reference/Microsoft/OData/Mcp/Core/Catalog/ODataMcpCatalogOptions#enforcerequiredoncreate)
is off), unknown properties on closed types, JSON kind per EDM type, `null` for non-nullable properties, enum
membership, and `MaxLength`. Keys containing `@` (annotations, `Nav@odata.bind`) and navigation
property names (deep insert) are passed through.
