## Summary

Projects a Core [EdmElicitForm](/api-reference/Microsoft/OData/Mcp/Core/Models/EdmElicitForm) onto SDK `ElicitRequestParams`.

## Remarks

Tools uses this mapper so remote `$metadata` can elicit without a McpEssentials
package reference. Field mapping matches McpEssentials `ElicitationField.ToSchema`.
