## Summary

Represents one named member of an [EdmEnumType](/api-reference/Microsoft/OData/Mcp/Core/Models/EdmEnumType).

## Remarks

The [EdmEnumMember.Value](/api-reference/Microsoft/OData/Mcp/Core/Models/EdmEnumMember#value) is the integral value declared in CSDL. It is the storage representation only;
JSON payloads carry the member [EdmEnumMember.Name](/api-reference/Microsoft/OData/Mcp/Core/Models/EdmEnumMember#name) by default.
