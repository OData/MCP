## Summary

How one step of a [ServiceProbe](/api-reference/Microsoft/OData/Mcp/Core/Diagnostics/ServiceProbe) ended.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Skipped` | 0 | The step was not attempted because an earlier step ruled it out. |
| `Passed` | 1 | The step succeeded. |
| `Unauthorized` | 2 | The service answered <c>401 Unauthorized</c>; the challenge is on the step. |
| `Forbidden` | 3 | The service answered <c>403 Forbidden</c>. |
| `NotFound` | 4 | The service answered <c>404 Not Found</c>. |
| `Unreadable` | 5 | The service answered, but not with something the catalog can use: HTML instead of CSDL, a body that is
            not JSON, or a row whose properties do not match the model. |
| `Failed` | 6 | The request failed for another reason: a 5xx, a transport error, or a timeout. |
