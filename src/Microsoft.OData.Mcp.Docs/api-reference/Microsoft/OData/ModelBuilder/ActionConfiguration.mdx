| `form` | `CloudNimble.McpEssentials.Core.Tasks.Elicitations.IFormElicitationSource` | The live form instance. |

Type: `Microsoft.OData.ModelBuilder.ActionConfiguration`
*action* so further configuration can chain.

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | Thrown when *action* or *form* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |

