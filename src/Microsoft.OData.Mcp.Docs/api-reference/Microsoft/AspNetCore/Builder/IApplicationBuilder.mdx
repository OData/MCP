## Methods

### <Icon icon="puzzle-piece" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> UseODataMcp <Badge color="green">Extension</Badge>

<Note>Extension method from `Microsoft.AspNetCore.Builder.ODataMcp_AspNetCore_ApplicationBuilderExtensions`</Note>

Maps official MCP HTTP endpoints at `{prefix}/mcp` for each OData prefix
enabled by `AddODataMcp`. Call this after OData routes are mapped
(`MapControllers`, `MapODataRoute`, or Restier `MapApiRoute`).

#### Syntax

```csharp
public static Microsoft.AspNetCore.Builder.IApplicationBuilder UseODataMcp(Microsoft.AspNetCore.Builder.IApplicationBuilder app)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `app` | `Microsoft.AspNetCore.Builder.IApplicationBuilder` | The application builder. |

#### Returns

Type: `Microsoft.AspNetCore.Builder.IApplicationBuilder`
The application builder.

#### Examples

```csharp
builder.Services.AddControllers()
    .AddOData(options =&gt; options.AddRouteComponents("odata", GetEdmModel()));
builder.Services.AddODataMcp();

var app = builder.Build();
app.UseRouting();
app.MapControllers();
app.UseODataMcp();
```

#### Remarks

`AddODataMcp` registers services only. This method turns MCP on. Do not call
the MCP SDK `MapMcp` yourself; this method invokes it per enabled prefix.
