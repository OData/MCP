## Methods

### <Icon icon="puzzle-piece" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> WithMcp <Badge color="green">Extension</Badge>

<Note>Extension method from `Microsoft.AspNetCore.OData.ODataOptionsMcpExtensions`</Note>

Enables MCP for this OData route only. Use when some routes must not be exposed to agents. Do not also call `AddODataMcp`.

#### Syntax

```csharp
public static Microsoft.AspNetCore.OData.ODataOptions WithMcp(Microsoft.AspNetCore.OData.ODataOptions options)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `options` | `Microsoft.AspNetCore.OData.ODataOptions` | The OData options whose most recently added route component should be exposed. |

#### Returns

Type: `Microsoft.AspNetCore.OData.ODataOptions`
The same [ODataOptions](/api-reference/Microsoft/AspNetCore/OData/ODataOptions) instance.

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | Thrown when *options* is null. |
| `InvalidOperationException` | Thrown when no route component has been added yet. |

#### Examples

```csharp
builder.Services
    .AddControllers()
    .AddOData(options =&gt;
    {
        options.AddRouteComponents("odata", GetPublicModel()).WithMcp();
        options.AddRouteComponents("internal", GetInternalModel());
    });
```

#### Remarks

Marks the last `AddRouteComponents` prefix. Do not call `AddODataMcp` in the same application.
