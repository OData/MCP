# Same model, three formats

An MCP client that wants to know what an OData service looks like can be handed the raw CSDL XML (`$metadata`), the same document as OData CSDL JSON, or the shapes this project emits. These are `cl100k_base` token counts of each, measured against the public Northwind and TripPin services. Every counted artifact is in [`Formats/`](./Formats); generated by `dotnet run -c Release -- --tokens` in `Microsoft.OData.Mcp.Benchmarks`.

CSDL JSON is written by EdmLib from the same model, compact (no whitespace), which is how a service would serve it. CSDL XML is counted exactly as the service returns it.

## One entity type

What a model receives when it asks about one type. The XML and JSON rows are the fragments of the full document that describe that type: the entity type, the enums it uses, the operations bound to it, and its entity set.
